GitHub Pages 部署

  1. 将整个项目文件夹上传到 GitHub 仓库。
  2. 进入 Settings → Pages。
  3. 选择 Deploy from a branch。
  4. 选择 main 分支与 /root 目录。

部署后数据存储于 Supabase 云端，与 GitHub 仓库无关，可多设备登录同步。
